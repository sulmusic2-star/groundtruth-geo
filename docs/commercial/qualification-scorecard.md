# Reply qualification scorecard

Score a vendor only after a written reply. Do not treat an opened email, a polite
compliment, or a request for a generic deck as demand.

| Signal | Points |
|---|---:|
| Names an address-specific answer or GIS workflow it wants tested | 3 |
| Can supply at least 20 real outputs with system/version context | 3 |
| Product, engineering, risk, or public-sector leader joins the email thread | 2 |
| Confirms official-record citations matter to customers or procurement | 2 |
| Has an evaluation, QA, assurance, or launch budget | 3 |
| Accepts written scoping and written delivery | 2 |
| Wants only a free benchmark badge, promotion, or open-source labor | -3 |
| Cannot disclose any outputs or permit testing | -3 |
| Wants certification, indemnity, or nationwide proof from the current set | -4 |

## Meaning

- **9–15:** qualified paid-evaluation opportunity; prepare a fixed scope.
- **5–8:** real fit discussion; ask for the missing case, owner, or budget fact.
- **1–4:** weak interest; do not build custom work yet.
- **0 or below:** archive unless the facts change.

## Commercial kill gate

After stable public proof, independent review, and 20 genuinely qualified
written approaches, require at least one of:

- a paid evaluation;
- a serious collaboration with a named owner, cases, schedule, and defined
  payment path; or
- a procurement request that names a budget and buying process.

If none occurs, keep GroundTruth-Geo as Lasting Ground's quality and credibility
system. Do not forecast it as a separate million-dollar business.
