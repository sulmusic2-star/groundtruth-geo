# Data handling for a paid evaluation

**Draft for scoping; not a certification, DPA, privacy policy or completed security review.**

## Operator

Tim Sullivan operates Lasting Ground as a United States sole proprietor. Lasting
Ground is not currently described as an LLC in buyer materials.

## Minimum-data approach

The evaluation is designed to use public property questions, vendor-generated
test outputs and public official records. It does not need names, resident
conversations, account credentials, payment data, health data or other personal
records.

Before accepting files, the written scope must state:

- exactly which fields the vendor will provide;
- whether any field is confidential;
- where the files will be stored and processed;
- whether an external model API may receive any part of a case;
- who can access the files;
- the retention and deletion date; and
- how deletion will be confirmed.

If the vendor cannot remove personal or production-confidential data, pause the
evaluation until appropriate contractual and technical controls exist.

## Default exclusions

- production credentials or API keys;
- private resident messages or contact information;
- legally restricted records;
- customer data not authorized for external evaluation;
- live changes to the vendor's system;
- automated decisions about a person; and
- permit questions in the current GroundTruth-Geo scope.

## Claims that must not be made yet

Do not claim SOC 2, ISO 27001, HIPAA compliance, a completed penetration test,
cyber-insurance coverage, a reviewed incident-response program or enterprise
data residency until each is documented and current.
